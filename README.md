# Ezz Client (Fabric 1.21.1)

Клиентский мод на Fabric 1.21.1 с системой модулей, клик-меню, HUD и чат-командами.

## Сборка
Локально: нужен JDK 21 и Gradle 8.10+ (`gradle build`).
На GitHub: Actions собирает автоматически при каждом пуше, JAR появляется в разделе Artifacts.

## Модули
- **FullBright** — убирает темноту (гамма 15)
- **Sprint** — постоянный спринт при движении вперёд
- **AutoWalk** — сам идёт вперёд
- **AutoRespawn** — возрождение после смерти
- **HUD** — оверлей: FPS, координаты, список включённых модулей
- **ClickGUI** — меню модулей (клавиша Right Shift)

## Чат-команды
- `.ezz help` — помощь
- `.ezz list` — список модулей и их состояние
- `.ezz toggle <имя>` — включить/выключить модуль

## Как добавить свой модуль
1. Создай класс в `com.ezz.client.modules`, унаследуй `Module`.
2. В конструкторе вызови `super("Имя", "Описание")`.
3. Переопредели `onTick` / `onEnable` / `onDisable` при необходимости.
4. Зарегистрируй в `EzzClient.onInitializeClient()` строкой `modules.register(new ИмяМодуля());`

Внимание: автоматические функции на многих серверах считаются читами и могут привести к бану.
